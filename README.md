## Fonctionnalités

- **Design moderne** en mode sombre avec animations fluides
- Navigation fixe avec mise en surbrillance automatique des sections
- Section Compétences avec onglets et barres de progression animées
- Formation présentée sous forme d’accordéon interactif (jQuery)
- Projets filtrables (Web / C-C++ / Base de données) via **React**
- Formulaire de contact avec validation en **jQuery**
- Entièrement responsive (mobile, tablette, desktop)
- Animations au scroll et effets de survol
